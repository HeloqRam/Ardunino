# Arduino proje arşivi

Bu depo, geçmiş ChatGPT görüşmelerindeki **üç Arduino çalışmasını** konu başlıklarına göre saklar.

| Klasör | Proje | Durum |
| --- | --- | --- |
| `rtc-lcd-saat/` | DS3231 RTC ve 16×2 LCD dijital saat | Önceki bağlantı/kütüphane bilgilerine göre **yeniden oluşturulmuş** kod |
| `hc-sr04-buzzer/` | HC-SR04 ultrasonik sensörle mesafe uyarısı | Önceki pin bilgilerine göre **yeniden oluşturulmuş** kod |
| `bluetooth-led/` | HC-05/HC-06 ile LED aç/kapat | Önceki pin ve komut bilgilerine göre **yeniden oluşturulmuş** kod |

> **Kaynak durumu:** 28–29 Haziran 2024 sohbetlerindeki proje işlevleri ve bazı pin/kütüphane bilgileri hatırlanabiliyor, ancak orijinal .ino dosyaları erişilebilir arşivde yok. Buradaki sketch dosyaları birebir tarihî kopya değil, yeniden hazırlanmış örneklerdir. Kart üzerinde test edilmemiştir.

Her projenin kendi klasöründeki README dosyasında bağlantılar ve kullanım bilgileri vardır.
